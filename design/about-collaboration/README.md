# Розділ About — блок співпраці Україна–США

Дизайн-джерело для секції `#about` на hordieiev.art: блок про співпрацю
з Дуайтом Роденом і Дезмондом Річардсоном (Complexions Contemporary Ballet)
та «Великого Гетсбі».

Живий канвас із варіантами й поясненнями:
https://claude.ai/code/artifact/4ed89925-c39c-414b-b859-3515cdb1652e

## Що тут лежить

| Файл | Що це |
|---|---|
| `gen.py` | генерує артборди `.dc.html` — шість штук: FR (три варіанти макета), EN, UA, мобільна |
| `canvas.json` | розкладка артбордів на канвасі + нотатки з логікою рішення |

Копія текстів у трьох мовах живе в `gen.py` у словниках `FR` / `EN` / `UK`.
Українська — майстер-версія, з неї перекладені інші дві.

## Як перегенерувати

```bash
python3 design/about-collaboration/gen.py
```

Артборди пишуться поруч зі скриптом і в git не потрапляють: у кожен зашиті
шрифти NAMU у base64 з `public/fonts`, тому файли по ~200 КБ.

## Де це на сайті

Розмітка — `src/app/[lang]/page.tsx`, секція `#about`.
Тексти редагуються в Notion Site Settings, ключі `about_collab_*`;
фолбеки — в `src/dictionaries/*.json` під ключами `about.collab*`.
