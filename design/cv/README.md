# Цифрове резюме — /[lang]/cv

Дизайн-джерело сторінки резюме на hordieiev.art. Резюме більше не веде на
`hordieiev-cv.surge.sh` — воно живе всередині сайту, а «Завантажити PDF»
друкує ту саму сторінку.

Живий канвас із поясненнями рішень, альтернативними напрямками, версією
для друку та трьома мовами:
https://claude.ai/code/artifact/94edc0f1-733e-44ac-94fd-56d8a889d311

## Що тут лежить

| Файл | Що це |
|---|---|
| `copy.json` | **єдине джерело тексту** резюме — `shared` (дати, музика, посилання) + `en` / `fr` / `uk` |
| `gen.py` | з `copy.json` робить артборди `.dc.html` **і** `src/lib/cv-data.ts` для сайту |
| `canvas.json` | розкладка артбордів + нотатки з логікою рішень |

Тому текст правиться в **одному** місці — `copy.json` — а не окремо в дизайні
й окремо в коді.

```bash
python3 design/cv/gen.py
```

Артборди пишуться поруч зі скриптом і в git не потрапляють: у кожен зашиті
шрифти NAMU у base64, тому файли по ~250 КБ.

## Як Артем передає правки

Він пише їх **просто на полотні, у дужках** поряд із текстом, якого вони
стосуються: `(зменшити кегль)`, `(червоним)`, `(прибрати цей рядок)`. Стосується
не лише тексту — розмірів, кольорів, відступів, верстки.

Порядок роботи: збережена версія приходить сповіщенням → зчитати артефакт →
`seed-canvas.mjs --extract` у порожню теку → порівняти з робочими файлами →
внести в `copy.json` (українську як майстер, далі FR і EN) → **видалити сам текст
у дужках**, бо це інструкція, а не контент → перегенерувати й перезберегти.

## Пастка: висота рамки артборда

`canvas.json` задає рамку числом. Якщо рамка нижча за артборд — **низ мовчки
обрізається**, без попередження; надлишок нешкідливий, він просто малює тло.
Тому після кожної правки, що додає текст або збільшує кеглі, висоти треба
переміряти, а не вгадувати.

Як переміряти: скопіювати артборди в `public/_m/` (знявши обгортку `x-dc`
і `helmet`), відкрити дев-сервер і зміряти в браузері кожен у своїй ширині
(Main/French/English 1440, Print 794, Mobile 390, Direction* 900), взяти
`scrollHeight` і додати ~6% запасу в `heights` у `gen.py`. Потім прибрати
`public/_m/`.

## Пастка: лапки у шрифтових стеках

`gen.py` вставляє шрифтові стеки прямо в `style="..."`. Якщо у стеку є
**подвійні** лапки — `"NAMU-1400", Georgia, serif` — атрибут обривається на
першій же з них, і артборд мовчки втрачає **всі** шрифти: документ падає на
Times, дрібний текст стає нечитабельним на чорному, і виглядає це так, ніби
«полотно порожнє».

Тому константи `DISPLAY` / `QUOTE` / `BODY` / `MONO` пишемо **лише з
одинарними** лапками. Перевірка:

```bash
grep -c 'style="[^"]*font-family:"' design/cv/*.dc.html   # має бути 0 усюди
```

Сайт цього не мав ніколи: там шрифти оголошені в `cv.css`, а не в атрибутах.

## Українська — майстер-версія, але правити можна будь-яку мову

Домовленість від 27.08.2026 була: Артем править тільки українську. З 03.09.2026
вона пом'якшена — усі три мови лежать поруч на першій сторінці канви й приймають
правки однаково. Українська лишається майстром у тому сенсі, що правка, яка
прийшла в ній, переноситься у дві інші; правка, яка прийшла у FR або EN,
зчитується саме з тієї мови й **не** переписується з української.

Ризик розходження трьох мов нікуди не зник (нагорода «Адіос» була записана
трьома різними способами в трьох мовах однієї картки, і це не помічали
місяцями), тож після кожного кола правок звіряти всі три артборди, а не лише
той, який правили.

Французька лишається версією для ринку, тож перекладається під французького
продюсера, а не слово в слово.

## Артборди

| Артборд | Що показує |
|---|---|
| `Main` | **UA — майстер-версія**, напрямок A «Траєкторія» |
| `French` / `English` | FR і EN — на тій самій сторінці, правляться так само |
| `Print` | FR на A4 (794 px = A4 при 96 dpi), `print: flow` — це те, що отримає французький театр |
| `Mobile` | UA на 390 px |
| `DirectionB` / `DirectionC` | два альтернативні напрямки — «розділене поле» і «регістр» |

## Дизайн-рішення

Резюме споріднене із сайтом, але свідомо не тотожне:

- та сама чорна основа, той самий червоний `#c8102e`, той самий NAMU-1400;
- **NAMU працює дрібно** — у трекованих мітках, а не як гігантський дисплей:
  це документ, а не афіша;
- доданий **моноширинний шар** (JetBrains Mono) для дат, статусів і цифр;
- увімкнене **золото `#d4af37`** — токен, який уже оголошений у `globals.css`,
  але на самому сайті ніде не використовується. Тут воно тримає українську
  вісь проти червоної американської в розділі 03;
- секції — у рамках із внутрішнім відступом, а не на всю ширину, як смуги сайту.

Головний елемент — графік траєкторії 2007→2026 з видимим провалом 2016–2020.
Він не декоративний: це і є аргумент резюме, показаний за секунду.

## Де це на сайті

| Шлях | Що |
|---|---|
| `src/app/[lang]/cv/page.tsx` | сама сторінка |
| `src/app/[lang]/cv/cv.css` | палітра як CSS-змінні + `@media print` |
| `src/components/CvActions.tsx` | «Завантажити PDF» / «Повернутись на сайт» |
| `src/lib/cv-data.ts` | **згенерований** — не правити руками |

`@media print` перевизначає **змінні**, а не правила, тож PDF — це буквально
ця сама сторінка на папері, а не окремий файл, який колись розійдеться з нею.
