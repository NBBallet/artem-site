# «Замовити» — чернетка розділу /[lang]/programmer

Espace pro: чотири формати (S1–S4), які французький програматор може замовити,
з тривалістю, складом, технічними умовами й карткою у PDF.

Живий канвас: https://claude.ai/code/artifact/d8de79e1-2ff3-4360-9ea8-404f641f8121

## Чому це чернетка

Розділ написали кодом 04.09.2026 (`813a34f`) і того ж дня влили в `main` —
Vercel зібрав і опублікував його автоматично. Артем побачив у продакшені
розділ, якого не затверджував. 14.09.2026 його звідти прибрано.

Прибрано **не видаленням, а прапорцем** — `src/lib/drafts.ts`:

| Де | Що робить прапорець |
|---|---|
| `src/app/[lang]/programmer/page.tsx` | без нього маршрут віддає 404, і навіть `title`/`description` назовні не йдуть |
| `src/components/Navbar.tsx` | без нього пункт меню не рендериться |

Подивитись розділ живим:

```bash
NEXT_PUBLIC_DRAFT_PROGRAMMER=1 npm run dev
```

У Vercel цієї змінної **немає і не треба додавати**. Реліз розділу — не
«увімкнути прапорець у хмарі», а прибрати `DRAFT_PROGRAMMER` із трьох файлів
одним комітом, коли правки з канваса внесені.

## Що тут лежить

| Файл | Що це |
|---|---|
| `gen.py` | малює артборди **з `src/lib/offers-data.ts`** — тексту в ньому немає |
| `canvas.json` | розкладка: «Що вирішити» + FR/EN/UA |

```bash
python3 design/programmer/gen.py
```

Артборди `.dc.html` і зібраний `zamovyty-chernetka.html` у git не йдуть:
у кожен зашитий NAMU у base64.

**Відмінність від `design/cv/`.** Там єдине джерело тексту — `copy.json`,
і `gen.py` робить із нього і артборди, і дані для сайту. Тут навпаки: джерело —
код сайту, а канвас лише його показує. Тому правки з канваса вносяться
в `src/lib/offers-data.ts`, а дзеркально — у `CHORÉGRAPHE/03 Товари/fiches.json`,
звідки `fiches.py` друкує ті самі чотири PDF. Розійдуться вони мовчки.

## Як Артем передає правки

Просто на полотні, у дужках поряд із текстом: `(прибрати цей рядок)`,
`(зменшити кегль)`. Порядок той самий, що в `design/cv/`: зчитати артефакт →
`seed-canvas.mjs --extract` → внести в `offers-data.ts` → **видалити текст
у дужках** → перегенерувати й перезберегти.

Артборд «Що вирішити» — список питань, на які чернетка чекає відповіді:
ціна, назва компанії й рядок про SIRET, конфлікт із `design/cohorts`,
назва пункту в навігації, форма контакту, передрук PDF.
