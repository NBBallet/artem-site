# Редактор на сайті — `/edit`

Заведено 28.09.2026 на прохання Артема: правити тексти сайту просто на
сторінці, щоб правка без посередників ставала на hordieiev.art.

## Як ним користуватись

1. `hordieiev.art/edit` → пароль → браузер пам'ятає вхід 180 днів.
   Вхід потрібен один раз на кожен пристрій.
2. Унизу будь-якої сторінки з'являється «✎ Правка», але тільки на цьому
   пристрої. Відвідувач цієї кнопки не бачить, а сервер без сесії правку
   не приймає.
3. «✎ Правка» → клік у текст → правиш → Enter або клік поза текстом.
   Змінені блоки позначаються червоною рискою зліва.
   Esc повертає блок як був, «Скасувати» — всю сторінку.
4. «Опублікувати» → звіт по кожній правці → «Збирається…» → «✅ На сайті».
5. «💬 Доручення» — для того, що не є текстом: розмір, колір, порядок
   блоків, фото. Доручення потрапляє в GitHub Issues з міткою
   `правка-сайту`, і Claude вносить його на наступній сесії:
   `gh issue list -R NBBallet/artem-site -l правка-сайту`.

## Мовне правило

Артем править українську або англійську версію. Правка переходить у дві
інші мови разом із перекладом. Французька перекладається для французького
програматора, а не слово в слово. Правка французької змінює тільки
французьку. Французькі рядки, які не можна перезаписувати перекладом,
вносяться в `src/content/fr-exceptions.json` (масив рядків).

## Що відбувається під час «Опублікувати»

```
POST /api/edit/publish
  → читає з GitHub усі файли з текстами (src/content, src/dictionaries,
    src/lib/*.ts, src/app/**/*.tsx, src/components, design/cv/copy.json)
  → шукає старий текст (пробіли, лапки, HTML-сутності, екранування)
  → Claude (claude-opus-5) отримує уривки, де текст живе, і повертає
    точні заміни: сама правка + переклад в інші мови на тих самих місцях
  → кожна заміна має збігтися в файлі рівно один раз, інакше нічого не пишеться
  → один коміт у гілку деплою (main у продакшні, своя гілка в preview)
  → Vercel перебудовує сайт, /api/edit/status стежить за деплоєм
```

Код: `src/lib/site-editor/` · панель: `src/components/SiteEditor.tsx` ·
вхід: `src/app/edit/page.tsx` · маршрути: `src/app/api/edit/*`.
Тести: `node --test test/site-editor.test.ts`.

## Змінні середовища у Vercel (Production і Preview)

| Змінна | Що це |
|---|---|
| `EDIT_PASSWORD` | пароль входу. Зміна пароля розлогінює всі пристрої |
| `ANTHROPIC_API_KEY` | ключ для перекладу правок |
| `GITHUB_TOKEN` | fine-grained токен тільки на `NBBallet/artem-site`: Contents — read/write, Issues — read/write, Deployments — read |

Необов'язкова `EDIT_BRANCH` явно задає гілку для комітів. Без неї береться
гілка поточного деплою (`VERCEL_GIT_COMMIT_REF`), а якщо й її немає — `main`.

Локально: `EDIT_PASSWORD` лежить у `.env.development.local` (в git не йде).
Без `GITHUB_TOKEN`/`ANTHROPIC_API_KEY` публікація чесно відповідає, що ключів
немає, а все інше (вхід, панель, позначки) працює.
